# QuitBeacon Web Agent Notes

## Purpose

This repository contains the public, dependency-free QuitBeacon website. Keep it separate from the private mobile and backend repositories.

## Rules

- Do not claim that a feature is available until it exists in the mobile app.
- Keep health language supportive and non-diagnostic. Do not make medical or outcome guarantees.
- Privacy, support, and data-handling copy must match the shipped app.
- Do not add trackers, advertising scripts, or third-party embeds without an explicit privacy review.
- Preserve keyboard accessibility, reduced-motion support, semantic HTML, and mobile responsiveness.
- Test every page locally before committing.
